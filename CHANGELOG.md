# Changelog

All notable changes to Sable will be documented in this file.

## [1.0.0-beta.1] — Unreleased

First public beta release of Sable.

### Features

- Soulseek integration for music search and downloads.
- Music library comparison and missing track detection.
- CSV, TXT, M3U and M3U8 support.
- Manual, preview and automatic recovery workflows.
- Audio integrity validation using FFmpeg and FFprobe.
- Metadata extraction and track identity verification.
- Persistent download and recovery history.
- Manual review and approval before importing tracks.
- Duplicate detection and safe file import.
- Guided external dependency configuration.
- Native Windows file and folder selection dialogs.
- Portable Windows x64 distribution.

### Privacy and security

- No telemetry or automatic diagnostic uploads.
- Protected credential handling.
- Local configuration and history storage.
- Explicit control over file import and deletion.

### Known limitations

- Windows x64 only.
- Sockseek, FFmpeg and FFprobe must be obtained separately.
- The application is currently in beta.

## Versioning

Sable follows semantic versioning.

Beta releases may contain defects and are intended for early adoption and community feedback.
