# Sable — Official Support

**Your music library deserves better.**

Sable is a free, privacy-focused Windows desktop application for music library recovery, management and audio validation.

Developed by **PARAGYN Studio**.

## Support and feedback

This repository is the official public support channel for Sable.

- [Report a bug](https://github.com/paragynstudio/sable-support/issues/new)
- [Suggest an improvement](https://github.com/paragynstudio/sable-support/issues/new)
- [Browse existing issues](https://github.com/paragynstudio/sable-support/issues)

Before opening an issue, please check whether it has already been reported.

Never include passwords, credentials, personal information or sensitive file paths in public reports.

## Our philosophy

**Take a little. Give a little. Keep music alive.**

Inspired by the spirit of sharing and reciprocity within the Soulseek community, Sable encourages responsible sharing, respect for fellow collectors and support for artists.

Sable is our way of giving back.

## Our commitment

- No ads.
- No subscriptions.
- No locked features.
- No telemetry.
- Voluntary financial support.

## About this repository

This repository contains public documentation, support resources and community feedback. Sable's application source code is maintained separately.

Sable is an independent application and is not officially affiliated with Soulseek or its developers.

Developed with AI-assisted engineering and design using ChatGPT and Codex.
