# Security Policy

## Supported versions

Security fixes are prioritized for the latest publicly available version of Sable.

As an independently developed application, Sable does not guarantee long-term support for previous releases.

## Reporting a vulnerability

If you discover a potential security vulnerability, please report it privately.

Use the [Report a vulnerability](https://github.com/paragynstudio/sable-support/security/advisories/new) option on GitHub.

Please include:

- Affected Sable version.
- A description of the vulnerability.
- Steps to reproduce the issue.
- Potential security impact.
- Relevant technical evidence, with sensitive information removed.

Do not disclose security vulnerabilities through public GitHub issues.

## Responsible disclosure

Please allow a reasonable opportunity to investigate and address reported vulnerabilities before publicly disclosing them.

Reports are handled on a best-effort basis. We appreciate responsible disclosure but cannot guarantee response times or financial rewards.

## Privacy

Never include passwords, authentication credentials, personal information or private music library contents in your reports.

Thank you for helping keep Sable and its community safe.
