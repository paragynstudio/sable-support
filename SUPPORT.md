# Sable — Support Guide

Thank you for using Sable!

## Before reporting an issue

- Make sure you are using the latest available version.
- Check that the required external tools are correctly configured.
- Search existing issues to avoid duplicate reports.
- Try to reproduce the problem.

## Reporting a bug

Please include:

- Sable version.
- Windows version.
- Steps to reproduce the issue.
- Expected and actual behavior.
- Relevant error messages or screenshots.

[Report a bug](https://github.com/paragynstudio/sable-support/issues/new)

## Privacy

Sable does not collect telemetry or automatically submit diagnostic information.

Before sharing screenshots or logs, remove:

- Passwords and credentials.
- Personal information.
- IP addresses and Soulseek usernames.
- Sensitive file paths and library contents.

## Feature requests

Suggestions are welcome. Please describe the problem you want to solve and how your proposed improvement would help.

## Support expectations

Sable is independently developed and distributed free of charge. Support is provided on a best-effort basis, without guaranteed response times.

## Support the project

Financial contributions are entirely optional and do not grant priority support or exclusive features.
